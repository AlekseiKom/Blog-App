## 2. Найденные и исправленные ошибки

### 2.1. Остаточная ширина вкладок на мобильных (`src/styles.css`)
В медиа-запросе `@media (max-width: 640px)` осталась старая строка из до-рефакторинговой вёрстки:
```css
.tabs { width: calc(100% - 24px); ... }
```
Из-за неё на маленьких экранах панель вкладок была уже шапки и сетки карточек (края не совпадали).
**Исправление:** `width` убран — `.tabs` теперь занимает всю ширину содержимого единого контейнера `.app-shell`, края ровные.

### 2.2. Конфликт классов иконки в пустых состояниях (`src/templates/card.template.js`)
`renderEmpty()` добавлял префикс `fa-solid` к иконкам, которые уже несли свой стиль:
- Заметки: получалось `class="fa-solid fa-regular fa-note-sticky"`
- Избранное: `class="fa-solid fa-regular fa-star"`

Два конфликтующих класса font-family — иконка могла рендериться неправильным весом.
**Исправление:** `<i class="${icon}">` — используется класс, переданный вызывающим кодом (все три вызова передают полный класс со стилем).

## 3. Выравнивание шапки / навигации / сетки карточек

**Причина бага на больших экранах:** `dist/` содержал старую сборку, где:
- `.app-header` — свой `max-width: 1080px` + собственный padding;
- `.tabs` — `width: calc(100% - 40px)` (почти весь экран);
- `#app` — свой `max-width: 1080px` с горизонтальным padding.

Поэтому верхние плашки были шире контейнера сетки, а левые/правые края не совпадали.

**Решение (уже было в `src/`, но не попало в сборку):** единый контейнер
```css
.app-shell { max-width: 1080px; margin: 0 auto; padding: 0 20px; }
```
Внутри него — `<header class="app-header">`, `<nav class="tabs">` и `<main id="app">`.
Все три блока теперь имеют **строго одинаковую ширину** (содержимое `.app-shell`) и ровные левый/правый края на любых экранах. Футер выровнен тем же `max-width: 1080px; margin: 0 auto; padding: 0 20px`.

**Действие:** выполнена пересборка `npm run build` — `dist/index.html`, `dist/styles.css`, `dist/bundle.js` обновлены (проверено: в `dist/index.html` есть `.app-shell`, содержимое `dist/styles.css` идентично `src/styles.css`).

## 4. Усиление эффекта стекла (выпуклый glassmorphism)

Добавлен общий приём «свет сверху»: светлая внутренняя кромка + тёмная нижняя грань + градиентный блик.

Новые переменные в `:root`:
```css
--glass-inset: inset 0 1px 0 rgba(255, 255, 255, 0.2), inset 0 -1px 0 rgba(6, 8, 24, 0.3);
--glass-edge-top: rgba(255, 255, 255, 0.3);
```

Что усилено:

| Элемент | Что сделано |
|---|---|
| `.glass` (шапка, вкладки, календарь, панель дня, модалки) | Градиентный блик поверх полупрозрачности, светлая верхняя граница (`border-top-color`), blur 18→20px + saturate 140%→160%, внутренняя тень `--glass-inset` + внешняя тень карточки |
| `.card` (плашечки-карточки) | Внутренний блик сверху/снизу, на hover — усиленный блик и более глубокая внешняя тень |
| `.btn` (все кнопки) | Светлая внутренняя кромка сверху; у `.btn-primary` / `.btn-danger` — яркая белая грань поверх градиента + свечение |
| `.tab.active` | Внутренний блик на градиентной вкладке |
| `.brand-icon`, `.btn-icon`, `.icon-btn` (иконки) | Стеклянная подложка + внутренний блик, усиливается на hover; у `.icon-btn` появилась постоянная лёгкая стеклянная плашка за иконкой |
| `.badge-*`, `.count-badge` (чипы/бейджи) | Внутренний блик сверху — эффект выпуклой таблетки |
| `.task-check.done`, `.cal-cell.today .cal-num` | Блик + цветное свечение на градиентных элементах |
| `.toast` | Светлая верхняя грань для стеклянного вида |

## 7. Автодеплой при редактировании (добавлено 05.10.2026)

Добавлен скрипт **`scripts/watch-deploy.js`** и npm-команда:

```bash
npm run watch
```

Как работает:
- следит за всеми файлами в `src/`;
- после последней правки (дебаунс 1 сек) автоматически запускает `npm run build`, а затем `firebase deploy --only hosting`;
- не запускает вторую сборку, пока идёт первая; ошибки показываются в консоли и не роняют процесс.

Проверено вживую: изменение файла → сборка (≈1 сек) → деплой на Firebase → «Deploy complete!» за ~13 секунд.

**Режим работы:** откройте терминал в папке `Blog-App`, запустите `npm run watch` и оставьте его открытым, пока правите код — каждая сохранённая правка сразу появляется на https://news-and-notes-blog-ak.web.app (на телефоне может потребоваться обновление страницы). Требуется действующий вход в Firebase (`firebase login`).

## 9. Единый вертикальный ритм на всех разрешениях (05.10.2026)

Проблема: на десктопе/планшете (>640px) отступ «вкладки → контент» был 22px, а «заголовок вкладки → карточки» и «между карточками» — по 16px; шапка→вкладки = 14px. В панели дня: заголовок→запись = 12px, между записями = 8px.

Всё приведено к единому ритму **16px** (внутри панели дня — 8px) на всех разрешениях:

| Правило | Было | Стало |
|---|---|---|
| `.app-header` top / margin-top (десктоп) | 12px / 12px | 16px / 16px |
| `.tabs` margin-top (десктоп) | 14px | 16px |
| `#app` padding-top (десктоп) | 22px | 16px |
| `.cal-day-head` margin-bottom | 12px | 8px (= отступ между записями `.cal-row`) |
| `.app-header` top / margin-top (мобильный) | 8px / 8px | 16px / 16px |

Не менялось (уже было 16px): `.view-head` margin-bottom, `gap` у `.cards-grid`, `margin-bottom` календарной панели, мобильные `#app`/`.tabs`. Цвета, эффекты стекла и JS не тронуты. Сборка пересобрана и задеплоена на Firebase Hosting.
